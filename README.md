# Einstein Busters (PICO-8)

A small PICO-8 game where you play as Albert Einstein defending science concepts!
Einstein moves left/right, jumps, and can launch gravity wells (mini black holes)
to pull in enemies.

## Controls

- **Left/Right** : Move Einstein
- **Up** : Jump
- **X/Z** : Launch a gravity well

## Running

1. Install [PICO-8](https://www.lexaloffle.com/pico-8.php)
2. Open the cartridge: `pico8 einstein_busters.p8 -run`

Or drag and drop the `.p8` file into the PICO-8 editor.

## Features

- Custom Einstein character sprite (pixel art)
- Gravity well projectiles that pull bullets and other objects
- Particle effects for jumps and shooting
- Parallax scrolling background
- Simple sound effects

## Development

The game is built with [PICO-8 Lua](https://www.lexaloffle.com/pico-8_manual.php).
All code is self-contained in a single `.p8` file.
